# Cast Player
Laptop → TV (Chromecast / Google TV) on the same Wi-Fi.

1. Install Python 3 (python.org), keep this folder on your laptop.
2. Run: `python serve.py "D:\Movies"` (or double-click `start.bat`, or drag a folder onto it).
3. Browser opens http://localhost:8000 → add videos from "Laptop library" → click **Cast** → pick TV.

First run: allow Python through Windows Firewall (Private networks). Use Chrome or Edge.
